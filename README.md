# カタカナ ふうせん

カタカナが苦手な子どもが、すでに読めるひらがなを手がかりに、カタカナを 1 文字ずつ覚えるためのゲームです。
iPad で遊ぶことを前提に作っています。

## 遊び方

- **ふうせん**: 「あ の カタカナは どれかな？」と読み上げられるので、正しいカタカナの風船を割ります
- **ことば**: 絵とことば（例: ラ□オン）を見て、空いているところに入る字を選びます
- **スタンプちょう**: 3 回続けて正解した字に、五十音表の形でスタンプがつきます

時間制限や減点はありません。はじめての字は正解が光って教えてくれます。
似ている字（シとツ、ソとン など）を取り違えたときは、違いを絵と声で見せます。

## iPad のホーム画面に置く

1. Safari でこのページを開く
2. 共有ボタン（四角から上向きの矢印）→「ホーム画面に追加」
3. 「追加」を押す

ホーム画面から開くと全画面で動きます。一度開けば、通信がなくても遊べます。

## 記録について

覚えた字やスタンプの記録は、その端末の中だけに保存されます。どこにも送信しません。
ホーム画面から開いた場合と Safari で開いた場合とでは、記録が別々になります。

## 使っているもの

- 書体: [Klee One](https://fonts.google.com/specimen/Klee+One)、[Zen Maru Gothic](https://fonts.google.com/specimen/Zen+Maru+Gothic)（どちらも SIL Open Font License。Google Fonts から読み込み）。アイコンの文字も Klee One です
- 読み上げは、端末の日本語音声（Web Speech API）を使います
